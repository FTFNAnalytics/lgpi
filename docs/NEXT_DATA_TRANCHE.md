# Next data tranche

## Immediate objective

Move the prototype from a strong transparency reconstruction to a broad 2023 financial database while keeping every value source-cited.

## Sequence

1. Quebec financial extraction is complete for all 19 LGPI municipalities. Do not independently score Quebec for the pitch build; preserve the published edition's explicit omission.
2. Resolve the Kawartha Lakes and Chatham-Kent publication conflicts.
3. Alberta reference extraction is complete: all 9 LGPI Alberta municipalities are generated from the official 2023 FIR/SIR workbook, with Calgary reconciled to its audited report.

5. Ontario FIR extraction is complete for the 40 source-available LGPI municipalities; Hamilton remains explicitly source-unavailable in Ontario's 2023 system.
6. Atlantic and territorial statement extraction is complete. All 99 LGPI municipalities now have either source-backed 2023 financial observations or an explicit source-unavailable state.
7. Reconcile and source the Statistics Canada dwelling denominators used by the historical LGPI.
8. Reproduce dollars-per-household and provincial-average calculations.
9. Run reconciliation checks against historical LGPI values that remain publicly accessible.

## Definition of complete for a municipality

A municipality is financially complete only when:

- every legacy field has an explicit observation state;
- every reported value has a source;
- source concepts are mapped to LGPI concepts;
- totals reconcile within documented tolerance;
- household denominator is sourced;
- calculated fields can be reproduced;
- unresolved exceptions are documented.
